# Casos de uso — Nomi Core

Los casos de uso describen comportamiento ejecutable, no sólo pantallas.

Cada caso define:

- actor;
- objetivo;
- entrada;
- precondiciones;
- flujo principal;
- transacción;
- salida;
- auditoría/eventos;
- errores;
- permisos;
- pruebas mínimas.
